Dokumentation als Aufmerksamkeit

Erst das Geschehen.
Dann die Deutung.

Eine kurze Beobachtung wird zur prüfbaren Episode. Das System ordnet und erinnert, aber es diagnostiziert, bewertet und ratifiziert nicht.

Grundsatz
„Nicht das Kind ist die Datenstruktur. Sein Weg ist die Datenstruktur.“

Diese Alpha nutzt ausschließlich einen fiktiven Demo-Fall und lokale Browserdaten.

Episode

Jede maschinelle Zuordnung bleibt Entwurf, bis eine verantwortliche Person sie prüft.

Noch keine Episode strukturiert.
